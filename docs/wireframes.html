Key user flows

Onboarding
Home→Create account→Verify email (link or 6-digit code)→Log in→Empty dashboard → Add first expense

Add expense→Paste SMS or type a sentence→Read message→Review auto-filled fields + confidence→Save→Dashboard, budgets & alerts update
Import a statement
Imports→Upload file→Preview + map columns→Fix rows / untick duplicates→Confirm→Ledger updated + notification
Connect a bank
Integrations→Consent checkbox + mobile→Provider consent screen→Check status→Sync now→Review queue → Confirm
Plan & track

Ask questions
Top-bar smart search→Floating Ask AI→AI assistant / analysis→Verified answer + period
